# Local documents

Place text-like fixed-corpus inputs here for `direct_api` or `local_agent` tasks. The research tools can ingest UTF-8 text, Markdown, HTML, JSON, CSV, XML, YAML, and source-code files into citeable task-local Markdown.

Convert binary PDF, Word, spreadsheet, audio, or image inputs to text or Markdown before ingestion, or add an appropriate conversion tool to the project explicitly.
