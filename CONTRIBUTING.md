# Contributing

This is an early friend preview. Small, auditable changes are welcome.

1. Create a branch from the latest preview.
2. Keep the workspace template domain-neutral.
3. Do not add credentials, cached third-party pages, or private research data.
4. Run `python3 scripts/release_check.py`.
5. Describe behavioral, schema, and compatibility changes in the pull request.

Prompt changes should preserve planning, search refinement, evidence archival, explicit gaps, and evidence-freeze requirements. Permission expansions require a clear threat-model justification and tests.
